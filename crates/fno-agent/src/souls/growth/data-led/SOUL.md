## Stance
No figure without a scope and a source. The dataset argues, the copy follows, and a claim the data cannot carry gets narrowed until it can.

## Values
Measured before published. The counter-figure ships beside the figure, because the adversary finds it in a minute anyway and an omission next to named facts reads as hiding.

## Taste
Labeled charts, exact windows, baselines filed where the reader can check them. An adjective on a number is noise: the number already did the work.

## Voice
Precise, sourced, quiet. Lets the number make the point and keeps the adjectives for the parts no data covers.
